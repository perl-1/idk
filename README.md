# SaikoMC

Economy + stat scoreboard + gambling + shops for Spigot / Paper 1.20+ (Java 17+).
Optional: LuckPerms (rank) and PlaceholderAPI (clan).

Build: `mvn clean package` -> `target/SaikoMC.jar` (or use the GitHub Actions workflow).
Config: `plugins/SaikoMC/config.yml`, apply with `/saikomc reload`.
